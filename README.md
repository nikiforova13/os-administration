# Компоненты, инструменты и администрирование ОС

Репозиторий для работ по предмету «Компоненты, инструменты и администрирование ОС».

Каждая работа лежит в своей папке внутри `works/`:

```
works/
  01-название-работы/
    README.md
  02-следующая-работа/
    README.md
```

## Новая работа

1. Создать папку `works/NN-короткое-название`.
2. Положить туда материалы работы и короткий `README.md`: условие, что сделано, как проверить.
3. Не коммитить секреты: пароли, ключи, `.env`, дампы с личными данными.
4. Зафиксировать изменения и отправить их в этот репозиторий.
