# Практическая работа № 12

## Вывод символов на дисплей КР580ВМ80

Цель работы — изучить вывод текстовой информации во внешнее устройство
микропроцессорной системы с помощью команды `OUT`.

Программа циклически выводит строку **«ОЛЯ ИЕВЛЕВА»** разноцветными символами.
Коды символов заданы в OEM-кодировке CP866. Перед каждым символом в порт `00H`
отправляется байт цвета, затем — код символа. Цвет увеличивается после каждого
символа и ограничивается маской `7FH`, поэтому старший бит всегда равен нулю
и монитор остаётся в текстовом режиме.

## Файлы

- `name-output.asm` — исходный текст программы с комментариями;
- `name-output.cod` — готовый образ ОЗУ для загрузки в эмулятор;
- `build_cod.py` — воспроизводимая сборка и проверка файла `.cod`.

## Запуск в эмуляторе

1. Распаковать предоставленный архив «КР580ВМ80 Ассемблер».
2. Запустить `K580BM80.EXE`.
3. Загрузить `name-output.cod` через меню работы с файлами. Начальный адрес
   загрузки — `0000H`.
4. Включить монитор через меню **Вид → Отобразить монитор**.
5. Установить адрес выполнения `0000H` и запустить программу.
6. Для завершения использовать кнопку остановки: программа специально работает
   в бесконечном цикле.

Ожидаемый результат — экран последовательно заполняется повторяющейся строкой
«ОЛЯ ИЕВЛЕВА», причём соседние символы имеют разные цвета.

## Карта памяти

| Адреса | Назначение |
|---|---|
| `0000H–0019H` | исполняемый код |
| `001AH–0024H` | строка «ОЛЯ ИЕВЛЕВА» в CP866 |

Байты строки:

```text
8E 8B 9F 20 88 85 82 8B 85 82 80
 О  Л  Я     И  Е  В  Л  Е  В  А
```

## Ручной ввод в ОЗУ

Если загрузка `.cod` недоступна, байты можно занести в память с адреса `0000H`:

```text
0000: 0E 01 21 1A 00 06 0B 79 D3 00 7E D3 00 0C 79 E6
0010: 7F 4F 23 05 C2 07 00 C3 02 00 8E 8B 9F 20 88 85
0020: 82 8B 85 82 80
```

## Алгоритм выполнения

| Адрес | Команда | Действие |
|---|---|---|
| `0000H` | `MVI C,01H` | записать в `C` начальный цвет |
| `0002H` | `LXI H,001AH` | записать в `HL` адрес первого символа |
| `0005H` | `MVI B,0BH` | установить счётчик из 11 символов |
| `0007H` | `MOV A,C` | перенести цвет в аккумулятор |
| `0008H` | `OUT 00H` | отправить цвет в порт монитора |
| `000AH` | `MOV A,M` | прочитать из памяти текущий код CP866 |
| `000BH` | `OUT 00H` | отправить код символа в порт монитора |
| `000DH` | `INR C` | увеличить цвет |
| `000EH` | `MOV A,C` | перенести новый цвет в аккумулятор |
| `000FH` | `ANI 7FH` | обнулить старший бит байта цвета |
| `0011H` | `MOV C,A` | сохранить нормализованный цвет |
| `0012H` | `INX H` | перейти к следующему символу в памяти |
| `0013H` | `DCR B` | уменьшить счётчик символов |
| `0014H` | `JNZ 0007H` | продолжить вывод, пока `B` не равен нулю |
| `0017H` | `JMP 0002H` | начать новый цикл вывода строки |
