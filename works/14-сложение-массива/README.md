# Практическая работа № 14

## Сложение массива с двухбайтным результатом

Цель работы — написать для КР580ВМ80А программу сложения массива
однобайтных беззнаковых чисел, выполняющую сложение в цикле и учитывающую
переполнение 8-разрядного аккумулятора.

Массив расположен в последовательных ячейках памяти, начиная с `0100H`.
Младший байт результата записывается в `0120H`, старший — в `0121H`.

## Файлы

- `array-sum.asm` — исходный текст программы с комментариями;
- `array-sum.cod` — готовый образ ОЗУ для загрузки с адреса `0000H`;
- `build_cod.py` — воспроизводимая сборка и проверка образа `.cod`.

## Исходные данные и результат

В работе используются пять чисел:

```text
Адрес:     0100 0101 0102 0103 0104
Значение:    A1   9B   F0   80   40
```

Их сумма:

```text
00A1H + 009BH + 00F0H + 0080H + 0040H = 02ECH
```

После выполнения программы память должна содержать:

```text
0120H = ECH  ; младший байт
0121H = 02H  ; старший байт
```

Получение результата по шагам:

| Слагаемое | Младший байт в `A` | Старший байт в `C` | Перенос |
|---|---:|---:|---|
| `A1H` | `A1H` | `00H` | нет |
| `9BH` | `3CH` | `01H` | есть |
| `F0H` | `2CH` | `02H` | есть |
| `80H` | `ACH` | `02H` | нет |
| `40H` | `ECH` | `02H` | нет |

## Запуск в эмуляторе

1. Распаковать архив «КР580ВМ80 Ассемблер».
2. Запустить `K580BM80.EXE`.
3. Загрузить `array-sum.cod` с начального адреса `0000H`.
4. До запуска проверить числа по адресам `0100H–0104H`.
5. Установить адрес выполнения `0000H` и запустить программу.
6. После остановки на `HLT` проверить `0120H` и `0121H`: там должны быть
   `ECH` и `02H`.

## Карта памяти

| Адреса | Назначение |
|---|---|
| `0000H–0018H` | исполняемый код |
| `0019H–00FFH` | заполнение нулями |
| `0100H–0104H` | пять элементов массива |
| `0105H–011FH` | свободная область, заполненная нулями |
| `0120H–0121H` | младший и старший байты результата |

## Машинный код

Если загрузка `.cod` недоступна, команды можно занести в память вручную:

```text
0000: 21 00 01 06 05 AF 4F 86 D2 0C 00 0C 23 05 C2 07
0010: 00 21 20 01 77 23 79 77 76
0100: A1 9B F0 80 40
0120: 00 00
```

## Алгоритм

| Адрес | Команда | Действие |
|---|---|---|
| `0000H` | `LXI H,0100H` | записать в `HL` адрес первого элемента |
| `0003H` | `MVI B,05H` | загрузить число элементов |
| `0005H` | `XRA A` | обнулить аккумулятор и флаг переноса |
| `0006H` | `MOV C,A` | обнулить старший байт суммы |
| `0007H` | `ADD M` | прибавить текущий элемент к `A` |
| `0008H` | `JNC 000CH` | пропустить учёт переноса, если его нет |
| `000BH` | `INR C` | увеличить старший байт при переполнении `A` |
| `000CH` | `INX H` | перейти к следующему элементу |
| `000DH` | `DCR B` | уменьшить счётчик элементов |
| `000EH` | `JNZ 0007H` | повторить цикл для оставшихся элементов |
| `0011H` | `LXI H,0120H` | перейти к области результата |
| `0014H` | `MOV M,A` | сохранить младший байт |
| `0015H` | `INX H` | перейти к адресу `0121H` |
| `0016H` | `MOV A,C` | перенести старший байт в аккумулятор |
| `0017H` | `MOV M,A` | сохранить старший байт |
| `0018H` | `HLT` | остановить выполнение |
